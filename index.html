About

Hellhound started as an independent GitHub organization for building the tools its founder wanted while doing security research. It has grown into a home for many projects, built by more than one person, each solving one specific problem.

Security is where we started, not where we stop. If we think it should exist, we build it, and we publish it openly.

We build what we think.

Offensive security

Autonomous agents and scanners for bug bounty, pentesting, OSINT and defense research.

Everyday apps

Normal apps for normal life, like habit trackers, with AI where it actually helps.

AI developer tools

Tools that make building software faster. We're working on these and they'll appear here as they ship.

Training labs

Intentionally vulnerable apps for practicing security testing safely.

    How we work

    Build first, explain later
    An idea becomes a working repo quickly. We improve it in public.
    Test on real targets
    Security tools run against vulnerable labs and real programs, then we fix what fails.
    Open by default
    Public code gets reviewed, broken and improved faster than private code.
